# Pet Health Analyzer

An AI-powered web application that analyzes pet photos to detect possible health conditions and suggests nearby veterinary hospitals and NGOs for help.

Features
- 📸 Upload a pet photo for instant AI-based health analysis
- 🏥 Suggests nearby veterinary hospitals based on location
- 🤝 Recommends nearby pet NGOs for rescue and support
- 🌐 Simple and user-friendly web interface

Tech Stack
- Frontend: HTML, CSS, JavaScript
- AI Integration: AI-powered image analysis
- Location Services: Nearby vet and NGO suggestions

How to Use
1. Open the website in your browser
2. Upload a photo of your pet
3. The AI analyzes the image and detects possible health issues
4. View suggested nearby veterinary hospitals and NGOs
